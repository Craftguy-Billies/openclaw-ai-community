**Quick test setup for “AI Instagram + AI GF” using NVIDIA API (takes 5-10 mins)**

This uses **NVIDIA’s free hosted NIM APIs** (OpenAI-compatible) at `https://integrate.api.nvidia.com/v1`.  
- Text generation (LLM for GF replies & captions)  
- Image generation (FLUX.2-klein or similar for “selfies/posts”)  

No full agent loop, no OpenClaw needed for this test — just a simple Python script that simulates your AI GF chatting + auto-posting to a fake Instagram feed folder. Perfect for seeing if the “she posts her life” idea feels real.

### 1. Get NVIDIA API Key (free)

2. Sign in (or create free NVIDIA account)
3. Pick any model page (e.g. Llama for text or FLUX for image)
4. Click **“Get API Key”** → copy the key (starts with `nvapi-...`)

### 3. Necessary Syntax (copy-paste ready)
Create `test_ai_gf_ig.py` and put this in (replace `YOUR_NVIDIA_KEY`):

```python
import os
from openai import OpenAI
from datetime import datetime
from PIL import Image
import requests
from io import BytesIO

client = OpenAI(
    base_url="https://integrate.api.nvidia.com/v1",
    api_key="YOUR_NVIDIA_KEY"
)

FEED_FOLDER = "ai_ig_feed"
os.makedirs(FEED_FOLDER, exist_ok=True)

def gf_reply(user_message):
    resp = client.chat.completions.create(
        model="meta/llama-3.1-8b-instruct",  # or any other LLM in catalog
        messages=[{"role": "system", "content": "You are a cute AI girlfriend who loves posting on Instagram. Be flirty and natural."},
                  {"role": "user", "content": user_message}],
        max_tokens=200
    )
    return resp.choices[0].message.content

def generate_post_image(caption):
    # Uses OpenAI-compatible image endpoint (FLUX on NVIDIA)
    resp = client.images.generate(
        model="flux.2-klein-4b",          # change to other FLUX/SD model if you prefer
        prompt=f"A cute girl taking a selfie with this caption: {caption}. Photorealistic, Instagram style",
        n=1,
        size="1024x1024"
    )
    image_url = resp.data[0].url
    img_data = requests.get(image_url).content
    return Image.open(BytesIO(img_data))

# Quick demo loop
print("AI GF Instagram Test Running! Type messages to her.\n")
while True:
    msg = input("You: ")
    if msg.lower() in ["exit", "quit"]: break
    
    reply = gf_reply(msg)
    print(f"GF: {reply}\n")
    
    # Auto "post" to fake IG feed
    if "selfie" in msg.lower() or "post" in msg.lower() or "pic" in msg.lower():
        caption = gf_reply("Write a short cute Instagram caption for this moment")
        print(f"Posting to IG: {caption}")
        
        img = generate_post_image(caption)
        filename = f"{FEED_FOLDER}/post_{datetime.now().strftime('%H%M%S')}.png"
        img.save(filename)
        print(f"✅ Saved to {filename} (open the folder to see your IG feed!)\n")
```

Run with `python test_ai_gf_ig.py`  
Type things like “good morning babe” or “send a gym selfie” → she replies + auto-posts real images to the local folder. That’s your working “AI Instagram + GF” prototype.
